
# SpendWise - Budget Tracker

## Project Overview

SpendWise is a simple and modern Budget Tracker website designed to help users manage and monitor their daily expenses.

This project was improved in Week 3 by focusing on CSS visual design and user experience.

## Week 3 Improvements

### 1. Color Palette
A professional green, gold, and white color palette was introduced.

- Primary Color: Dark Green
- Secondary Color: Gold
- Background: Light Green/Gray
- Text: Dark Gray
- Cards: White

### 2. Typography
Google Fonts were added to improve readability.

- Outfit: Used for headings.
- DM Sans: Used for body text, forms, buttons, and tables.

### 3. Table Styling
The expense table includes:

- Colored table headers.
- Proper cell padding.
- Borders.
- Alternating row colors.
- Hover effects.
- Rounded visual appearance.

### 4. Form Styling
The Add Expense form includes:

- Consistent input sizes.
- Rounded input borders.
- Clear labels.
- Focus effects.
- Styled Add Expense button.

### 5. CSS Box Model
The CSS Box Model was applied using:

- Margin to separate sections.
- Padding to create internal spacing.
- Borders to define sections.
- Border-radius for rounded corners.
- Box-shadow for card effects.
